# One-Sentence Absurd Invention Pitch

A single-sentence pitch for the WaveSaver, a wristband that rescues you from
waving back at someone who was waving at the person behind you.

## Run

```sh
python3 main.py
```

This writes the pitch to `/output/entry.txt` (creating the directory if needed).
